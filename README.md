# Neo24 AI for Android

Neo24 AI is an Android client for the Neo24 AI service at https://neo24.ai.

This repository contains the free and open-source Android edition of Neo24 AI intended for distribution through F-Droid and other independent Android distribution channels.

## Features

- AI chat through Neo24 AI
- Text input
- Speech input
- Text-to-speech output
- Camera and image upload
- File upload
- User account login
- Browser-based authentication
- Compatible with Neo24 AI user accounts

## F-Droid edition

This edition uses the application ID:

`ai.neo24.app.fdroid`

It does not include Google Play Billing or native Google Play Services authentication.

Google authentication, where available, is handled through the user's web browser and the Neo24 AI server.

## Requirements

- Android 8.0 (API level 26) or newer
- Internet connection
- A Neo24 AI account for account-based features
